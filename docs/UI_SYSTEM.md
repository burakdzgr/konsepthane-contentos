# Konsepthane ContentOS UI System

The normal operator experience uses one visual and interaction language across every workspace.

- Deep navy application canvas and fixed navigation rail
- Purple/blue Konsepthane ContentOS identity
- Global search in the top bar
- Compact cards with restrained borders instead of database-admin chrome
- Blue for selection, green for healthy/complete, amber for attention, red for blocked/error and purple for AI/editorial concepts
- Turkish-first labels; technical vocabulary remains inside advanced controls
- Real backend values only; visual references never authorize fabricated integrations, metrics, progress or content

The primary operator route is:

`Kontrol Merkezi → Kaynaklar → Araştırmalar → Fikirler → Fırsatlar → İçerikler → Onaylar`

Strategy and performance support the editorial route. Agents, integrations and system health remain available without becoming steps that a normal operator must manage every day.

`studio.css` is imported after the legacy global stylesheet. It owns the shared application shell and cross-screen component grammar while established page-specific classes continue to render real domain data.
